# MoonRego development instructions

- Follow `docs/superpowers/plans/2026-10-23-moonrego-v0.1.md`.
- Use test-driven development for every behavior change.
- Keep source files focused and separate top-level blocks with `///|`.
- Run `moon check --deny-warn` and `moon test --deny-warn` before reporting a
  completed step.
- Do not weaken warnings or edit generated `.mbti` files manually.
- Do not access GitHub or create commits until the owner supplies the correct
  Git author identity.
