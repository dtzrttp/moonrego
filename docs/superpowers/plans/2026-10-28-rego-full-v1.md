# Full Rego v1 implementation plan

**Goal:** Deliver complete Rego v1 language semantics verified against OPA
v1.21.4, without claiming unimplemented behavior as complete.

**Architecture:** Evolve MoonRego's syntax, compiler and evaluator in tested
vertical slices; track the full grammar, runtime values, all pinned built-ins,
host effects and cross-target behavior in docs/rego-v1-roadmap.md. Preserve
the native CLI as an adapter. Use first-party tests and an independent pinned
OPA oracle and conformance corpus when available.

**Constraints:** Work locally; no GitHub operations. Keep the submission
document outside the repository. Use the current stable MoonBit toolchain,
test-first development, meaningful commits, and do not manually edit generated
interfaces. Unexecuted oracle expectations must not be called observations.

## First slice: ordered complete rules

- [x] Add parser and end-to-end regressions for first-match ordering, repeated
  else clauses, false results, defaults, conflicts and branch-local variables;
  run the native tests and observe the unsupported else syntax fail.
- [x] Model the chain and parse conditional and unconditional value forms, including diagnostics for
  default/set rule misuse; preserve source spans and the existing constructor.
- [x] Check every branch in a separate scope and include its head/body in
  recursion analysis. Evaluate branches in order and stop at the first defined
  result while preserving shared budget and error propagation.
- [x] Run parser, compiler, evaluator and conformance tests on all targets,
  format, check and build, generate and review interfaces, and document the
  exact supported forms and remaining oracle gap.

## Remaining endpoint milestones

- [ ] Acquire and verify the pinned OPA binary, capabilities manifest and
  applicable conformance corpus from an authorized source; record provenance.
- [ ] Implement remaining rules and expressions including user functions,
  with, rule reference heads, full binding/unification and value semantics.
- [ ] Implement every pinned builtin and its host capabilities; run deterministic
  host and differential tests on every supported target.
- [ ] Complete the pinned conformance and differential matrix with no known
  semantic gaps; publish commands, results, limitations and evidence.
